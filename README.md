## Formato de los DBA

Cada DBA tiene su **enunciado exacto** (en negrita, la idea central que destaca el MEN), las **habilidades** o
evidencias que desarrolla y, cuando el documento lo trae, un **ejemplo explicado**: qué hace el estudiante y una
muestra del nivel esperado. Los ejemplos son ilustrativos: sirven de base para crear variantes en planes y actividades.
