# Lectura Crítica · Saber 11° · taxonomía del ICFES

Fuente: Guía de orientación del Examen Saber 11º 2026-2 (Calendario A) (`fuentes/icfes/guia-orientacion-saber11-2026-2.pdf`). Textos literales del PDF, con su página.

Esta prueba evalúa las habilidades de entender, interpretar y evaluar textos que pueden encontrarse tanto en la vida cotidiana como en ámbitos académicos no especializados. Se espera que los estudiantes que culminan la educación media cuenten con las capacidades lectoras para tomar posturas críticas frente a esta clase de textos. (pág. 39)

## Competencia, afirmaciones y evidencias

### `LEC-C1` Competencia lectora (pág. 39)

De acuerdo con el Marco de referencia de esta prueba, se evalúa la competencia lectora, la cual involucra, de manera general, los procesos cognitivos necesarios para leer de manera crítica diferentes tipos de texto.

La guía desagrega la competencia en tres procesos cognitivos; cada uno se recoge en una afirmación.

#### Proceso 1 · Identificar y ubicar información local · 25 % de las preguntas (pág. 40)

Este proceso se relaciona con la capacidad para comprender el significado de las palabras, expresiones y frases que aparecen explícitamente en el texto. La evaluación de este proceso no indaga por conocimientos propios de la gramática, pero sí por la comprensión de las relaciones semánticas que existen entre los diferentes elementos que constituyen una oración. En esa medida, permite dar respuesta a preguntas como: ¿qué?, ¿dónde?, ¿cuándo?, ¿quién?, ¿de qué manera?, ¿con quién? La afirmación que recoge este proceso es: Identifica y entiende los contenidos locales que conforman un texto.

- **Afirmación** `LEC-A1` Identifica y entiende los contenidos locales que conforman un texto.
  - `LEC-E1.1` Entiende el significado de los elementos locales que constituyen un texto.
  - `LEC-E1.2` Identifica los eventos narrados de manera explícita en un texto (literario, descriptivo, caricatura o cómic) y los personajes involucrados (si los hay).

#### Proceso 2 · Relacionar e interpretar información · 42 % de las preguntas (pág. 41)

Este proceso se relaciona con la capacidad para comprender cómo se relacionan formal y semánticamente los elementos locales que constituyen un texto, de manera que este adquiera un sentido global (a nivel de párrafos, secciones, capítulos, etcétera). En esa medida, las preguntas correspondientes a este proceso cognitivo involucran varios elementos locales de un texto (por ejemplo, diferentes frases o párrafos) y exigen reconocer y comprender su articulación. En este proceso de lectura se activa el conocimiento previo del lector, quien relaciona la información del texto para obtener conclusiones, plantear una hipótesis, hacer generalizaciones, comprender el lenguaje implícito. La afirmación que recoge este proceso es Comprende cómo se articulan las partes de un texto para darle un sentido global.

- **Afirmación** `LEC-A2` Comprende cómo se articulan las partes de un texto para darle un sentido global.
  - `LEC-E2.1` Comprende la estructura formal de un texto y la función de sus partes.
  - `LEC-E2.2` Identifica y caracteriza las diferentes voces o situaciones presentes en un texto.
  - `LEC-E2.3` Comprende las relaciones entre diferentes partes o enunciados de un texto.
  - `LEC-E2.4` Identifica y caracteriza las ideas o afirmaciones presentes en un texto informativo.
  - `LEC-E2.5` Identifica el tipo de relación existente entre diferentes elementos de un texto (discontinuo).

#### Proceso 3 · Evaluar y reflexionar sobre la forma y el contenido de los textos · 33 % de las preguntas (pág. 42)

Este proceso se relaciona con la capacidad para enfrentar un texto críticamente e implica identificar la intención comunicativa del autor y reflexionar sobre la forma y el contenido del texto. Incluye evaluar la validez de argumentos, advertir supuestos, derivar implicaciones, reconocer estrategias argumentativas y retóricas, relacionar contenidos con variables contextuales, etcétera. Se trata de la habilidad propiamente crítica y, como tal, exige un ejercicio adecuado de las dos anteriores. La afirmación que recoge este proceso es Reflexiona a partir de un texto y evalúa su contenido.

- **Afirmación** `LEC-A3` Reflexiona a partir de un texto y evalúa su contenido.
  - `LEC-E3.1` Establece la validez e implicaciones de un enunciado de un texto (argumentativo o expositivo).
  - `LEC-E3.2` Establece relaciones entre un texto y otros textos o enunciados.
  - `LEC-E3.3` Reconoce contenidos valorativos presentes en un texto.
  - `LEC-E3.4` Reconoce las estrategias discursivas en un texto.
  - `LEC-E3.5` Contextualiza adecuadamente un texto o la información contenida en este.
